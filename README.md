# activityLogger
A simple point solution that digests engagements(transcripts/recordings/chat) and outputs consistent data reliably and at scale is a massive time saver for the users and value benefit to a business.
TAM: 
BizDev/Sales/Success teams

Premise: 
Users spend untold amount of admin time logging the activity when businesses want them DOING activity. This is compounded when RevOps/UX/CX want to understand a customers journey more or the nuance within.
Developing a simple point solution that digests engagements(transcripts/recordings/chat) and outputs consistent data reliably and at scale is a massive time saver for the users and value benefit to a business.

- Domain/Subdomains:
    - Interaction:
        - Call
        - Email
        - Chat
        - Text/DM
    - User:
        - Audit logs
        - Login
        - Password reset
    - System of Record:
        - API calls
        - Payload orchestration
        - Payload routing
    - Engagement Connection:
        - Authorization
        - Management
        - Data mapping
        - Logs
